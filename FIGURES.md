# What produces each figure and table in the paper

The manuscript numbers its assets; this repository names them by
content. Three columns: the number as it appears in the paper, the
file name on disk, and what produces it.

Pass the **third** column to `--only`, not the file name:

    python3 scripts/generate_figures.py --only task_figure

Rows naming a notebook are produced by opening that notebook, not by
the figure runner. Rows saying `see PIPELINE.txt` come from a stage
documented there rather than from a single target.

The appendix counts separately and in letters, as the paper does, so
Fig 1 and Fig A are different assets. Generated by
`scripts/build_figure_index.py` from the manuscript, so the numbering
follows whatever the paper currently compiles.
